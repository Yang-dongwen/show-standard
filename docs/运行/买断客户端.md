# 买断客户端（本地版 · 与 SaaS 无关）

单店本机使用。数据在 **本机 SQLite**，**没有** 运营台、**没有** 小程序 / uni-app。

---

## 1. 开发态：浏览器访问

### 准备

- JDK 17、Maven、Node.js 18+
- 不必装 MySQL

### 步骤

```powershell
# 在仓库根目录

# 首次：装依赖并构建门店前端
cd frontend
npm install
npm run build
cd ..

# 以买断 / desktop 模式启动（SQLite）
mvn spring-boot:run -DskipTests "-Dspring-boot.run.profiles=desktop"
```

浏览器打开：**http://localhost:8080**

- 首次进入若提示安装向导，选 **本地买断**
- 按页面注册店长后即可用

### 前端热更新（可选）

```powershell
# 终端 1：后端
mvn spring-boot:run -DskipTests "-Dspring-boot.run.profiles=desktop"

# 终端 2：门店前端
cd frontend
npm run dev
# 浏览器 http://localhost:3000
```

### 数据在哪

- 库文件：用户目录下 `~/.show/show.db`（Windows 一般是 `C:\Users\你的用户名\.show\show.db`）
- 选型结果：`~/.show/install.properties`

---

## 2. 打成 Windows 安装包（MSI）

### 准备

- 完整 **JDK 17**（含 `jpackage`）
- 打 **MSI** 需要 [WiX Toolset 3.x](https://wixtoolset.org/)（`candle` 在 PATH）
- 也可在脚本里改成只打 exe

### 步骤

```powershell
# 仓库根目录
.\scripts\compile_all.ps1      # 构建前端 + fat jar
.\scripts\package-desktop.bat  # jpackage 出安装包
```

产物一般在：`dist\Show-*.msi`（或 exe）

安装后本机运行，仍是 **SQLite 买断**，与云无关。

改版本号：同步 `pom.xml` 与 `scripts/package-desktop.ps1` 里的版本。

---

## 3. 仅跑已有 jar（买断）

```powershell
# 先保证 frontend 已 build 进 jar（或 static/ 已更新）
mvn -DskipTests package

java -jar target\ddmo-1.0.0.jar --spring.profiles.active=desktop
```

---

## 4. 不要做的事

| 错误做法 | 原因 |
|----------|------|
| 买断版去连 MySQL / 开 `/saas/` | 产品线关闭，运营台不可用 |
| 买断版接小程序 / uni-app | 微信要公网 HTTPS，且数据在本机访问不到 |
| 日常开发用了 cloud 配置却当买断交付 | 会连上 MySQL，变成云版行为 |

需要运营台、多店、小程序 → 请看 [SaaS云版.md](./SaaS云版.md)。
