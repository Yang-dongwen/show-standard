# 微信原生小程序（miniprogram-biz）

目录：`miniprogram-biz/`  
原生微信小程序工程，**无 npm**。与 uni-app **共用同一套云版 API**，适合对照或继续用原生工具链。

**前提：后端是 SaaS 云版**（见 [SaaS云版.md](./SaaS云版.md)）。买断版不可用。

新项目优先建议用 [uni-app.md](./uni-app.md)。

---

## 1. 启动后端

本机或 Docker 把云版跑在可访问地址，例如：

```powershell
mvn spring-boot:run -DskipTests
# 默认 cloud + MySQL，端口 8080
```

确认 `application-cloud.yml`（或运行配置）里：

- `app.wx.miniapp.enabled=true`
- 开发联调：`app.wx.miniapp.mock=true`（可不访问微信服务器）

---

## 2. 改接口地址

编辑：`miniprogram-biz/utils/config.js`

```js
module.exports = {
  // 模拟器可用 127.0.0.1
  // 真机调试改成电脑局域网 IP，如 http://192.168.1.8:8080
  baseUrl: 'http://127.0.0.1:8080',
  productNote: '需云版 SaaS；本地安装包不使用本小程序'
}
```

正式环境改为：`https://你的域名`（不要末尾乱加路径）。

---

## 3. 微信开发者工具

1. 打开微信开发者工具 → **导入项目**  
2. 目录选：`miniprogram-biz`（整个文件夹）  
3. AppID：测试号或正式号  
4. 详情 → 本地设置 → 勾选：**不校验合法域名、web-view、TLS…**  
5. 用 **云版店长账号** 登录（与门店网页相同）

---

## 4. 能做什么

| 页面 | 说明 |
|------|------|
| 登录 | 账密；微信一键登录 + 首次绑定 |
| 首页 | 经营数据 |
| 会员 | 列表 / 编辑 |
| 收银 | 充值 / 消费 |
| 员工 / 服务 / 报表 / 门店 | 与 C 端 API 对齐 |

请求封装：`utils/request.js`（`wx.request` + Bearer Token）。

---

## 5. 正式上线检查

| 项 | 说明 |
|----|------|
| HTTPS 公网域名 | 微信要求 request 合法域名必须是 https |
| `baseUrl` | 改为正式 `https://...` |
| 公众平台 | 配置 request 合法域名 |
| 后端 | `mock=false`，真实 `app-id` / `app-secret` |
| 生产 | 建议 `app.security.strict-cloud=true`，改掉默认运营账号 |

---

## 6. 和 uni-app 怎么选

| | 原生 `miniprogram-biz` | uni-app `frontend-uniapp` |
|--|----------------------|---------------------------|
| 安装 | 无 npm | 需要 `npm install` |
| 导入目录 | `miniprogram-biz` | `dist/dev/mp-weixin` |
| H5 / App | 无 | 有 H5；App 预留 |
| API | 同一套 `/api/**` | 同一套 `/api/**` |

---

## 7. 常见问题

| 现象 | 处理 |
|------|------|
| request 失败 | 开发环境勾选不校验域名；检查 baseUrl |
| 真机失败 | baseUrl 用电脑 IP，手机与电脑同一 WiFi |
| wx-login 异常 | 确认 cloud 已开、mock 配置、jar 为较新构建 |
| 登录不上 | 先用网页确认店长账号可用，或运营台重置密码 |
