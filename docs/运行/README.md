# 运行与部署（只看这里）

本目录只讲 **怎么跑起来、怎么部署**。按你要交付的形态选一篇即可。

## 先选哪条路？

| 你要什么 | 打开文档 |
|----------|----------|
| **单店本机 / 可离线 / 买断**（SQLite，无运营台、无小程序） | [买断客户端.md](./买断客户端.md) |
| **SaaS 云版**：MySQL + 门店网页 + 运营台（可再接小程序） | [SaaS云版.md](./SaaS云版.md) |
| **商家 uni-app**（微信小程序 / H5，一套 Vue3 代码） | [uni-app.md](./uni-app.md) |
| **微信原生小程序**（`miniprogram-biz`，对照工程） | [微信小程序.md](./微信小程序.md) |

## 必须知道的规则

1. **买断版** 和 **SaaS 云版** 是两条产品线，不要混用数据库。
2. **小程序 / uni-app 只能连 SaaS 云版**（公网 HTTPS 或本机联调 cloud），**不能**连买断 SQLite。
3. 环境统一要求：**JDK 17**、**Maven 3.8+**、**Node.js 18+**（桌面包还要完整 JDK 的 jpackage）。

## 仓库里对应目录

| 目录 | 是什么 |
|------|--------|
| `frontend/` | 门店网页（C 端） |
| `frontend-saas/` | SaaS 运营台网页 |

| `miniprogram-biz/` | 商家微信原生小程序 |
| `src/` | Java 后端 |
| `scripts/` | 打包、冒烟脚本 |
| `docker-compose.yml` | 云版一键（MySQL + 应用） |
