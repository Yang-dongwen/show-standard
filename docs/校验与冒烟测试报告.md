## 3. G1–G9 闭环状态

| ID | 原问题 | 状态 | 实现要点 |
|----|--------|------|----------|
| **G1** | 无 Bean Validation | **已修** | `spring-boot-starter-validation`；核心 DTO 注解；`@Valid` 挂 Controller；`MethodArgumentNotValidException` / `ConstraintViolationException` → 400 |
| **G2** | 姓名/备注无长度上限 | **已修** | 会员名/员工名/服务名 ≤32；备注 ≤200；前后端 + 小程序 + 业务层双重校验 |
| **G3** | 金额无上限/小数位 | **已修** | 上限 `99999999.99`，最多 2 位小数；`@DecimalMax`/`@Digits` + Service `normalizeMoney`；前端/小程序同步 |
| **G4** | 设置 key 任意写 | **已修** | 白名单仅 `dailyTarget` |
| **G5** | SaaS 登录/开店无 rules | **已修** | `LoginView` / `OpenShopView` Element Plus `rules` + validate |
| **G6** | product-line 需登录 | **已修** | `AuthFilter` 公开 `/api/system/product-line` |
| **G7** | 备份路径硬编码 | **已修** | `BackupService.dbPath()` 从 `jdbc:sqlite:` URL 解析 |
| **G8** | 无跨租户越权自动化 | **已修** | `TenantIsolationIT`：B 不可改 A 会员/员工/余额/消费 |
| **G9** | 无角色权限矩阵 | **已修** | `RolePermissionMatrixIT`：cashier/staff 403 抽查 + owner 全通 |

## 4. 校验对照（当前）

| 场景 | 后端 | C 端 Web | 小程序 | SaaS UI |
|------|------|----------|--------|---------|
| 登录非空 | `@NotBlank` + 业务 | rules | 有 | **rules** |
| 注册密码≥6 / 昵称≤6 | `@Size` + 业务 | rules | n/a | 开店 **rules** |
| 金额 >0 且 ≤上限、2 位小数 | 有 | 有 | 有 | n/a |
| 消费校验码 4 位 | 有 | rules | 有 | n/a |
| 手机号 `1\d{10}` | `@Pattern` + 业务 | rules | 有 | n/a |
| 姓名/备注长度 | 有 | rules | 有 | n/a |
| 设置项白名单 | 有 | 依赖后端 | n/a | n/a |
| 空 body | 400 | — | — | — |
| 500 不泄密 | 有 | — | — | — |
| 跨租户 | tenant 过滤 + IT | — | — | — |
| 角色权限 | interceptor + IT | 菜单 | 登录态 | SaaS 独立 |
