# 开发与运行

本文说明 **Show**（理发店会员管理）的本地开发、调试与构建。

> 需要 **客户端 + SaaS + 小程序** 全套安装步骤时，请直接看 **[项目完整运行手册.md](./项目完整运行手册.md)**。

## 1. 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| C 端前端 | Vue 3 + Vite + Element Plus | `frontend/` → `static/`，开发端口 3000 |
| SaaS 前端 | Vue 3 + Vite + Element Plus | `frontend-saas/` → `static-saas/`，开发端口 3001 |
| 后端 | Spring Boot 3.1.5 + JDBC | C 端 `/api/**` + SaaS `/api/saas/**` |
| 数据库 | **两套方案 + Flyway** | **日常开发默认 MySQL**（`cloud`）；买断验证用 SQLite（`desktop`） |

- 入口：`com.ddmo.app.DdmoApplication`
- **日常开发库**：MySQL（`application-cloud.yml`，改账号密码只改这一处）
- **买断版库**：SQLite `~/.show/show.db`（`application-desktop.yml`）
- **迁移**：Flyway，`db/migration/mysql` · `db/migration/sqlite`
- 默认端口：`8080`

### 数据库怎么选

| 需求 | 启动 | 库 |
|------|------|-----|
| **日常本地测试（默认）** | `mvn spring-boot:run` | **MySQL**（`profiles=cloud` 已默认） |
| 验证本地买断 / 打包前 | `mvn spring-boot:run "-Dspring-boot.run.profiles=desktop"` | SQLite |

### 安装向导

| 项 | 说明 |
|----|------|
| 入口 | 首次打开 `/#/setup`（未完成时登录会被引导至此） |
| 配置文件 | `~/.show/install.properties` |
| API | `GET /api/install/status` · `POST /api/install/test-mysql` · `POST /api/install/complete` |
| 本地买断 | 写 edition=local → **才**固定 SQLite，通常无需重启 |
| SaaS | 写 MySQL + cloud，**重启**后生效 |
| 桌面包未选型 | `desktop.mode` 下临时 SQLite 仅拉起向导，不算买断 |

### Flyway 约定

| 项 | 说明 |
|----|------|
| 本地脚本 | `src/main/resources/db/migration/sqlite/V*.sql` |
| 云脚本 | `src/main/resources/db/migration/mysql/V*.sql` |
| 命名 | `V{版本}__描述.sql`，例如 `V2__add_punch_card.sql` |
| 已有库 | `baseline-on-migrate=true`，已有表则标为 V1 不重跑 |
| 禁止 | 修改已发布的 V 脚本；结构变更只追加新版本 |
| 双方言 | 同一功能两边同版本号各写一份 SQL |

旧库若 baseline 后缺列：开发可删 `~/.show/show.db` 重建；生产补 `V2` 或手工 `ALTER`。

## 4. 日常开发（默认 MySQL，无需打包）

前提：本机 MySQL 已建库 `show`，账号与 `application-cloud.yml` 一致（当前示例 `admin` / `123456`）。

### 4.1 仅后端 + 已构建静态资源

```powershell
mvn spring-boot:run -DskipTests
```

打开 `http://localhost:8080`（C 端）、`http://localhost:8080/saas/`（SaaS）。  
默认已是 **cloud + MySQL**，不必再写 `profiles=cloud`。

### 4.2 前端 HMR

```powershell
# 终端 1
mvn spring-boot:run -DskipTests

# 终端 2 · C 端
cd frontend
npm run dev
# http://localhost:3000

# 终端 3 · SaaS（可选）
cd frontend-saas
npm run dev
# http://localhost:3001/saas/
```

### 4.3 验证「本地买断 / SQLite」（偶尔）

```powershell
mvn spring-boot:run -DskipTests "-Dspring-boot.run.profiles=desktop"
```

### 4.4 一键构建 / 桌面安装包（最后验收再做）

```powershell
.\scripts\compile_all.ps1
# 桌面包：
.\scripts\package-desktop.bat
```

见 [桌面客户端打包.md](./桌面客户端打包.md)。

```powershell
.\scripts\compile_all.ps1
.\scripts\package-desktop.bat
```

## 6. 常见问题

| 问题 | 处理 |
|------|------|
| 端口占用 | 改 `server.port`，或 `--server.port=8081` |
| 8080 前端未更新 | 重新 `npm run build`，或用 `npm run dev` |
| 登录失败 | 查注册策略 `first-only`；SaaS 默认 `platform` / `platform123` |
