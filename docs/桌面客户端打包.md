# 桌面客户端打包（本地买断版）

> **本包仅交付 SKU A：本地买断版**（SQLite、离线、无小程序、无 SaaS）。  
> SaaS 云版请用 Docker/云主机，见 [云版Docker部署.md](./云版Docker部署.md)、[产品双轨说明.md](./产品双轨说明.md)。

在 **不影响 Web 联调** 的前提下，打成 Windows 可安装程序（优先 MSI）。  
用户电脑 **不需要安装 JDK**（安装包内嵌 runtime），**不需要安装 MySQL**。

## 1. 原则

1. 安装包固定 `app.deployment=desktop`，**禁止** cloud profile / 云 MySQL。  
2. 正常 `mvn spring-boot:run` / `java -jar`：不自动开浏览器。  
3. `scripts\package-desktop.bat` 一键打包。  

## 2. 桌面开关

主启动类 `DdmoApplication` + `DesktopSupport`：

| 开关 | 行为 |
|------|------|
| 默认 | 纯 Web |
| `-Ddesktop.mode=true` | 非 headless；单实例；系统托盘；就绪后打开 UI |

打开 UI 优先 **Edge/Chrome 应用模式**（`--app=URL`，无地址栏/标签）；失败再系统默认浏览器。  
托盘 **Exit Show** 才是真正退出。  
**不做内嵌 WebView**（体积与维护成本高，app 模式已够用）。

安装包通过 jpackage 注入：

- `-Ddesktop.mode=true`（托盘 + 浏览器壳）  
- `-Dapp.deployment=desktop`  
- 清空 `spring.profiles.active`（避免误用 cloud/MySQL）

## 3. 打包脚本

均在 `scripts/` 目录：

| 文件 | 说明 |
|------|------|
| `scripts/package-desktop.bat` | 启动器（纯 ASCII） |
| `scripts/package-desktop.ps1` | 配置与逻辑（改版本/msi·exe 在此） |
| `scripts/compile_all.ps1` | 发版前：前端 + fat jar |

配置区要点：`$AppName`、`$AppVersion`、`$MainJar`、`$PackageType`（`msi` / `exe`）、`$IconPath`。  
脚本会自动以仓库根为工作目录（`logo.ico`、`target/`、`dist/` 仍在根下）。

流程：检查工具 → `mvn clean package -DskipTests` → jlink 运行时 → jpackage → 打开 `dist\`。

改 exe：`$PackageType = "exe"`（可不装 WiX）。

## 4. 准备

| 角色 | JDK |
|------|-----|
| 打包机 | 需要完整 JDK 17+（jlink / jpackage） |
| 最终用户 | **不需要** |

另需：Maven；打 MSI 需 WiX 3.x（`candle` 在 PATH）；发版前先构建前端进 `static/`。

```powershell
java -version
jpackage --version
mvn -version
```

## 5. 使用

```powershell
# 日常 Web（无桌面行为）
mvn spring-boot:run

# 验证桌面开关
java -Ddesktop.mode=true -jar target\ddmo-1.0.0.jar

# 发版
.\scripts\compile_all.ps1
.\scripts\package-desktop.bat
```

产物示例：`dist\Show-1.0.0.msi`。

改版本：同步 `pom.xml` 与 `scripts/package-desktop.ps1` 中 `$AppVersion`、`$MainJar`。

## 6. 常见问题

| 问题 | 处理 |
|------|------|
| Failed to launch JVM | 关浏览器≠退出；托盘 Exit；或 `Stop-Process -Name Show -Force`；日志 `~\.show\desktop.log` |
| 无黑窗 | 默认无控制台；调试可加 `--win-console` |
| 端口占用 | 改 `server.port` 或启动参数 |
| jpackage / WiX | MSI 需 WiX；或改 exe |
| 页面空白 | 确认已 `npm run build` 进 static |

## 7. 与 Web 构建关系

| 脚本 | 作用 |
|------|------|
| `scripts/compile_all.ps1` | 前端 + fat jar |
| `scripts/package-desktop.bat` | jar + jpackage 安装包 |

建议：`.\scripts\compile_all.ps1` → `.\scripts\package-desktop.bat`。
