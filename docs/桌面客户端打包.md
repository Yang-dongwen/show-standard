# 桌面客户端打包

> 打 Windows 安装包（MSI/EXE），**不**在打包时写死 SQLite。  
> 用户首次启动走 **安装向导**：选「本地买断」→ SQLite；选「SaaS 云版」→ MySQL。  
> 产品说明见 [产品双轨说明.md](./产品双轨说明.md)。

在不影响 Web 联调的前提下打包。用户电脑 **不需要 JDK**（内嵌 runtime）。

## 1. 原则

1. 安装包只注入 **桌面壳**（`-Ddesktop.mode=true`：托盘、单实例、浏览器打开）。  
2. **不**强制 `desktop` profile / SQLite；数据库类型由安装向导决定。  
3. 未选型时：桌面壳临时用 SQLite **仅用于拉起向导**（`install.bootstrap`），不算已选买断。  
4. 日常开发默认 MySQL：`mvn spring-boot:run`（`cloud`），**不必打包**。

## 2. 桌面开关

| 开关 | 行为 |
|------|------|
| 默认 jar | 纯 Web，默认 cloud/MySQL |
| `-Ddesktop.mode=true` | 非 headless；单实例；托盘；就绪后打开 UI；未安装时 bootstrap SQLite 给向导 |

打开 UI 优先 Edge/Chrome 应用模式；托盘 **Exit Show** 才退出。

## 3. 打包脚本

| 文件 | 说明 |
|------|------|
| `scripts/package-desktop.bat` | 启动器 |
| `scripts/package-desktop.ps1` | 配置与逻辑 |

流程：`mvn package` → jlink → jpackage → `dist\`。

## 4. 使用

```powershell
# 日常开发（MySQL，不打包）
mvn spring-boot:run -DskipTests

# 最后验收安装包效果
.\scripts\compile_all.ps1
.\scripts\package-desktop.bat
```

安装后首次运行 → `/#/setup` 选版本。

## 5. 与产品选型

| 向导选择 | 数据 | 重启 |
|----------|------|------|
| 本地买断 | SQLite `~/.show/show.db` | 通常不需要 |
| SaaS 云版 | MySQL（向导里填） | **需要重启** |

配置落盘：`~/.show/install.properties`。
