## 1. 产品与交付形态

Show 是理发店会员与收银系统，**客户安装时二选一**（SKU）：

| 选型 | 卖法 | 数据库 | 门店 C 端 | SaaS 运营台 | 商家小程序 | 典型交付 |
|------|------|--------|-----------|-------------|------------|----------|
| **A · 本地买断** | 一次性买断 | 本机 **SQLite** | ✅ Web / 桌面 MSI | ❌ 关闭 | ❌ 关闭 | Windows 安装包 / 本机 jar |
| **B · SaaS 云版** | 订阅 | 云端 **MySQL** | ✅ 浏览器 | ✅ `/saas/` | ✅ | Docker / 云主机 |

**硬规则：**

1. 本地买断 **绝不** 连云 MySQL，也 **不** 开小程序 / SaaS。  
2. SaaS **必须** 用 MySQL；小程序 **只** 挂在云版。  
3. 同一套后端代码，靠 `app.deployment` + `spring.profiles.active` 切换能力。

```text
只想本店本机、可离线
  → 路线 A（默认 SQLite / 桌面包）

要多店开通、运营台、微信小程序
  → 路线 B（cloud profile + MySQL）
```

选型细节见 [产品双轨说明.md](./产品双轨说明.md)。

## 3. 通用环境安装

### 3.1 开发机必备

| 工具 | 版本要求 | 用途 |
|------|----------|------|
| **JDK** | **17**（完整 JDK，非 JRE） | 运行与打包；桌面包还需 `jlink` / `jpackage` |
| **Maven** | 3.8+ | 后端构建 |
| **Node.js** | **18+**（建议 LTS） | 两个 Vue 工程 |
| **Git** | 任意近期版 | 拉取代码 |

**Windows 验证：**

```powershell
java -version          # 应显示 17
mvn -version
node -v
npm -v
```

可选环境变量：`JAVA_HOME`、`MAVEN_HOME`、`NODE_HOME`（`scripts/compile_all.ps1` 会读入 PATH）。

### 3.2 按路线额外安装

| 路线 | 额外依赖 |
|------|----------|
| A · 仅本机 Web | 无（SQLite 自动建库） |
| A · 打 Windows MSI | WiX Toolset **3.x**（`candle` 在 PATH）；完整 JDK 17+ |
| B · 本机联调 | MySQL **8**（本机或容器） |
| B · Docker 一键 | Docker Desktop / Docker Engine + Compose |
| 小程序 | [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)；正式环境还需小程序 AppID |

### 3.3 首次克隆后的前端依赖

**不要在仓库根目录执行 `npm install`。** 依赖分别装在子工程内：

```powershell
# 门店 C 端（本地 / 云都需要）
cd frontend
npm install
cd ..

# SaaS 运营台（仅路线 B 需要）
cd frontend-saas
npm install
cd ..
```

小程序 **无 npm 依赖**，直接用微信开发者工具打开 `miniprogram-biz/`。

## 4. 路线 A：本地买断版（客户端）

目标：单店本机使用，数据在 `~/.show/show.db`，无需 MySQL、无小程序。

### 4.1 方式一：开发态（Maven + 浏览器）

**步骤 1 — 构建 C 端静态资源**

```powershell
cd frontend
npm install
npm run build
# 输出到 src/main/resources/static/
cd ..
```

或一键（C 端 + jar）：

```powershell
.\scripts\compile_all.ps1
```

**步骤 2 — 启动后端（默认 desktop + SQLite）**

```powershell
mvn spring-boot:run
```

**步骤 3 — 浏览器访问**

| 地址 | 说明 |
|------|------|
| http://localhost:8080 | 门店 Web |
| http://localhost:8080/#/setup | 首次安装向导（未写 `install.properties` 时） |
| http://localhost:8080/saas/ | 本地版会 **门禁/说明页**，不提供运营台 |

**步骤 4 — 注册店长**

- 默认注册策略：`app.register.mode=first-only`（仅允许首个店长注册）  
- 打开登录页，按提示注册 → 登录后使用会员 / 收银等功能  

**本机数据路径（Windows）：**

| 路径 | 内容 |
|------|------|
| `%USERPROFILE%\.show\show.db` | SQLite 库 |
| `%USERPROFILE%\.show\secrets.properties` | JWT 等密钥（首次自动生成，勿提交） |
| `%USERPROFILE%\.show\install.properties` | 安装选型（向导写入） |
| `%USERPROFILE%\.show\backups\` | 备份目录 |

Linux / macOS：`~/.show/`。

---

### 4.2 方式二：前端热更新开发

适合改 Vue 页面时：

```powershell
# 终端 1 · 后端
mvn spring-boot:run

# 终端 2 · C 端 HMR
cd frontend
npm run dev
# 浏览器打开 http://127.0.0.1:3000  （/api 代理到 8080）
```

注意：开发服务器只服务 `frontend/`，**不** 带 SaaS 页面（SaaS 见路线 B）。

---

### 4.3 方式三：fat jar 运行

```powershell
.\scripts\compile_all.ps1
java -jar target\ddmo-1.0.0.jar
```

带桌面托盘 / 自动开浏览器壳（与 MSI 行为接近）：

```powershell
java -Ddesktop.mode=true -jar target\ddmo-1.0.0.jar
```

- 托盘 **Exit Show** 才是真正退出  
- 优先用 Edge/Chrome `--app=` 模式打开

### 4.4 方式四：Windows 桌面安装包（最终用户）

**打包机要求：** JDK 17+（含 jpackage/jlink）、Maven、Node（用于先构建前端）、打 MSI 时需 WiX 3.x。

**最终用户：无需安装 JDK / Node / MySQL。**

```powershell
# 1) 先打进 static（本地版只需 C 端）
.\scripts\compile_all.ps1

# 2) jpackage → dist\Show-*.msi
.\scripts\package-desktop.bat
```

| 产物 | 路径 |
|------|------|
| 安装包 | `dist\Show-1.0.0.msi`（或改配置为 exe） |
| 中间产物 | `build\`（可清理，已在 `.gitignore`） |

安装包注入：

- `-Ddesktop.mode=true`  
- `-Dapp.deployment=desktop`  
- 内嵌 JRE runtime  

改版本：同步 `pom.xml` 与 `scripts/package-desktop.ps1` 中 `$AppVersion`、`$MainJar`。  
详情见 [桌面客户端打包.md](./桌面客户端打包.md)。

## 5. 路线 B：SaaS 云版

目标：MySQL + 门店 C 端云 API + SaaS 运营台 +（可选）商家小程序。

### 5.1 方式一：Docker Compose（推荐联调 / 演示）

**前提：** Docker 已安装并可用。

**步骤 1 — 构建两个前端（强烈建议，否则镜像内页面可能是旧资源）**

```powershell
cd frontend
npm install
npm run build
cd ..\frontend-saas
npm install
npm run build
cd ..
```

**步骤 2 — 启动**

```powershell
docker compose up -d --build
```

| 服务 | 容器名 | 说明 |
|------|--------|------|
| MySQL 8 | `show-db` | 库 `show` / 用户 `show` / 密码 `show`；root `showroot` |
| 应用 | `show-app` | `SPRING_PROFILES_ACTIVE=cloud`，端口 **8080** |

**步骤 3 — 访问**

| 端 | URL |
|----|-----|
| 门店 C 端 | http://localhost:8080/ |
| SaaS 运营台 | http://localhost:8080/saas/ |

**步骤 4 — 运维常用**

```powershell
docker compose logs -f app
docker compose ps
docker compose down          # 停服务，保留数据卷
docker compose down -v       # 停服务并清库（危险）
```

数据卷：`show_mysql_data`（MySQL）、`show_app_data`（`/root/.show`）。

---

### 5.2 方式二：本机 Maven + 本机/容器 MySQL

**步骤 1 — 准备 MySQL 8**

仅起数据库容器示例：

```powershell
docker compose up -d db
```

或本机安装 MySQL 后执行（见 `docker/mysql-init/README.md`）：

```sql
CREATE DATABASE IF NOT EXISTS show DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER IF NOT EXISTS 'show'@'%' IDENTIFIED BY 'show';
GRANT ALL PRIVILEGES ON show.* TO 'show'@'%';
FLUSH PRIVILEGES;
```

默认连接（`application-cloud.yml`）：

- URL：`jdbc:mysql://127.0.0.1:3306/show?...`
- 用户 / 密码：`show` / `show`

**步骤 2 — 构建前端**

```powershell
cd frontend
npm install
npm run build
cd ..\frontend-saas
npm install
npm run build
cd ..
```

**步骤 3 — 以 cloud 启动**

```powershell
mvn spring-boot:run "-Dspring-boot.run.profiles=cloud"
```

或：

```powershell
java -jar target\ddmo-1.0.0.jar --spring.profiles.active=cloud
```

Flyway 会执行 `db/migration/mysql/V*.sql` 自动建表。

---

### 5.3 方式三：SaaS / C 端前端热更新

```powershell
# 终端 1 · 后端（cloud）
mvn spring-boot:run "-Dspring-boot.run.profiles=cloud"

# 终端 2 · 门店 C 端
cd frontend
npm run dev
# http://127.0.0.1:3000

# 终端 3 · SaaS
cd frontend-saas
npm run dev
# http://127.0.0.1:3001/saas/
```

### 5.4 SaaS 运营台使用流程（摘要）

1. 打开 `/saas/`，使用引导账号登录（见 [§8](#8-默认账号与访问地址)）。  
2. 在运营台管理 **邀请码 / 租户 / 套餐 / 公告 / 驾驶舱**。  
3. 店长侧：通过邀请开店或 C 端注册策略建店（云上开店以 SaaS 邀请为主）。  
4. 租户停用、到期、只读等管控由 SaaS 写入，C 端请求即时生效。  

API 边界：

| 系统 | 前缀 | Token |
|------|------|-------|
| 门店 | `/api/**` | JWT `typ=manager` + `tenant_id` |
| 运营台 | `/api/saas/**` | JWT `typ=saas` |

**禁止** Token 跨系统互调。详见 [SaaS运营平台.md](./SaaS运营平台.md)。

### 5.5 云主机 jar 部署（无 Docker）

```powershell
# 构建机
cd frontend ; npm ci ; npm run build ; cd ..
cd frontend-saas ; npm ci ; npm run build ; cd ..
mvn -DskipTests package

# 服务器：JDK 17 + MySQL 已就绪
java -Xms256m -Xmx512m -jar ddmo-1.0.0.jar --spring.profiles.active=cloud
```

生产请用环境变量或外部配置覆盖数据源与密钥，勿使用示例密码。HTTPS 可用前置 Nginx（参考 `docker/nginx.conf`）或云负载均衡。

## 6. 商家微信小程序

> **前提：路线 B（云版）已启动。** 本地买断版 `app.wx.miniapp.enabled=false`，不支持小程序。

工程目录：`miniprogram-biz/`（原生小程序，无 npm）。

### 6.1 本地开发联调

| 步骤 | 操作 |
|------|------|
| 1 | 后端以 **cloud** 启动（Docker 或 `profiles=cloud`） |
| 2 | 确认 `application-cloud.yml` 中 `app.wx.miniapp.enabled=true`（默认 true） |
| 3 | 联调阶段保持 `mock: true`（不访问微信服务器） |
| 4 | 编辑 `miniprogram-biz/utils/config.js`：`baseUrl` 指向后端 |
| 5 | 微信开发者工具 → 导入项目 → 目录选 `miniprogram-biz` |
| 6 | 详情 → 本地设置 → **不校验合法域名、web-view、TLS…** |

`config.js` 示例：

```js
module.exports = {
  // 模拟器可用 127.0.0.1；真机调试改成电脑局域网 IP，如 http://192.168.1.8:8080
  baseUrl: 'http://127.0.0.1:8080',
  productNote: '需云版 SaaS；本地安装包不使用本小程序'
}
```

### 6.2 功能与 Web 对照

| 小程序页 | 对应 C 端 | 主要 API |
|----------|-----------|----------|
| 登录 | Login | `POST /api/auth/login`、微信绑定相关 |
| 首页 | Dashboard | 报表 / 总览 |
| 会员 | Customers | `/api/customers` |
| 收银 | Transactions | 充值 / 消费 |
| 员工 / 服务 / 报表 / 门店 | 对应页 | `/api/employees` 等 |

微信相关：

| 接口 | 说明 |
|------|------|
| `POST /api/auth/wx-login` | code → 已绑定发 JWT / 否则 preToken |
| `POST /api/auth/wx-bind` | 绑定店长账号 |
| `GET /api/auth/wx-bind-status` | 绑定状态 |
| `POST /api/auth/wx-unbind` | 解绑 |

`mock: true` 时可不依赖真实 AppID 完成业务联调。

### 6.3 正式环境上线

| 检查项 | 说明 |
|--------|------|
| 公网 **HTTPS** | 微信强制合法 request 域名必须是 https |
| `baseUrl` | 改为 `https://你的域名`（无尾斜杠路径问题按实际） |
| 微信公众平台 | 配置 request 合法域名 |
| 后端 | `app.wx.miniapp.mock=false`，填写真实 `app-id` / `app-secret` |
| 生产门禁 | 建议 `app.security.strict-cloud=true` |
| 引导账号 | 关闭或改掉默认 `platform123`（见生产清单） |

详情见 [商家小程序.md](./商家小程序.md)、[云版Docker部署.md](./云版Docker部署.md)。

## 7. 安装向导与本机配置

首次打开 C 端且尚未完成选型时，会进入 **`/#/setup`**：

1. 选择 **本地买断** 或 **SaaS 云版**  
2. 选 SaaS 时填写并测试 MySQL  
3. 写入 `~/.show/install.properties`  
4. 选 SaaS 后需 **重启应用** 使 cloud / 数据源生效  

| API | 用途 |
|-----|------|
| `GET /api/install/status` | 是否已安装 / 当前状态 |
| `POST /api/install/test-mysql` | 测试 MySQL |
| `POST /api/install/complete` | 完成向导 |

重做选型：删除 `~/.show/install.properties` 后重启（注意已有业务库的处理，见产品双轨说明）。

查询当前 SKU：`GET /api/system/product-line`。

## 9. 配置项速查

主配置：`src/main/resources/application.yml`  
云覆盖：`src/main/resources/application-cloud.yml`

| 配置 | 本地默认 | 云版（cloud） | 说明 |
|------|----------|---------------|------|
| `app.deployment` | `desktop` | `cloud` | SKU 门禁 |
| `spring.datasource` | SQLite `~/.show/show.db` | MySQL | Flyway 路径随之切换 |
| `app.saas.bootstrap-enabled` | true | true（生产改 false） | 是否允许创建引导管理员 |
| `app.wx.miniapp.enabled` | false | true | 小程序能力 |
| `app.wx.miniapp.mock` | true | true（上线改 false） | 假微信联调 |
| `app.security.strict-cloud` | false | false（生产改 true） | 禁止 mock/弱密钥等 |
| `server.port` | 8080 | 8080 | 可 `--server.port=8081` |
| `app.register.mode` | first-only | first-only | open / first-only / invite |

Docker 通过环境变量覆盖数据源示例：

```text
SPRING_PROFILES_ACTIVE=cloud
SPRING_DATASOURCE_URL=jdbc:mysql://db:3306/show?...
SPRING_DATASOURCE_USERNAME=show
SPRING_DATASOURCE_PASSWORD=show
```

## 10. 脚本与构建产物

```powershell
docker compose up -d --build
```

| 产物目录 | 是否应提交 | 说明 |
|----------|------------|------|
| `target/` | 否 | Maven 输出 |
| `build/`、`dist/` | 否 | 桌面打包中间/最终包 |
| `**/node_modules/` | 否 | 各前端自行 `npm install` |
| `src/main/resources/static*` | 视发布策略 | 发版前构建生成 |

脚本说明见 `scripts/README.md`。

## 12. 常见问题

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 8080 打开白屏 / 旧页面 | 未重新 `npm run build` | 进 `frontend`（及 saas）构建；或用 `npm run dev` |
| 端口占用 | 8080/3306 已被占用 | `--server.port=8081` 或停旧进程 |
| 本地版访问 `/saas/` 无运营台 | SKU 门禁 | 正常；改用 cloud profile |
| cloud 启动连不上库 | MySQL 未起 / 账号不对 | 先 `docker compose up -d db`；核对 yml |
| SaaS 无法登录 | 非 cloud 或引导未建 | 确认 profile；空库且 bootstrap 开启 |
| 小程序 request 失败 | 域名校验 / baseUrl / 非 HTTPS | 开发勾选不校验；正式配合法域名 |
| 小程序连不上真机 | `127.0.0.1` 指向手机自己 | `baseUrl` 改为电脑局域网 IP |
| jpackage MSI 失败 | 无 WiX | 安装 WiX 3.x，或 `$PackageType = "exe"` |
| database is locked | SQLite 多连接 | 本地版连接池已收敛；避免多进程写同一库 |
| 登录失败 | 无店长 / 策略限制 | `first-only` 先注册；云看租户是否停用/到期 |
| 根目录误装 npm | 错误在根 `npm install` | 删除根 `node_modules`；在 `frontend*` 下安装 |

集成测试（可选）：

```powershell
mvn test
```
