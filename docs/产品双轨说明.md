# 产品双轨说明（客户安装选型）

> 客户安装时**二选一**。进度见 [实现进度.md](./实现进度.md)。

## 客户怎么选（安装向导）

首次启动（未生成 `~/.show/install.properties`）会进入 **安装向导** UI（`/#/setup`）：

1. 选择 **本地买断版** 或 **SaaS 云版**  
2. SaaS 需填写 / 测试 **MySQL** 连接  
3. 写入本机配置；选 SaaS 后 **重启应用** 生效  

| 选型 | 卖法 | 数据 | 小程序 | SaaS 运营台 | 典型交付 |
|------|------|------|--------|-------------|----------|
| **A · 本地买断版** | 一次性买断 | **仅本机 SQLite** | ❌ 不支持 | ❌ 关闭 | Windows MSI / 本机 jar |
| **B · SaaS 云版** | 订阅 / 按年 | **云端 MySQL** | ✅ 商家小程序 | ✅ `/saas/` | 云主机 / Docker / 向导选 SaaS |

```text
只想本店本机用、不依赖外网、可离线
  → 向导选「本地买断」

要多店开通、平台管控、微信小程序
  → 向导选「SaaS 云版」并配置 MySQL（或服务器直接 cloud profile）
```

重装选型：删除 `~/.show/install.properties` 后重启，会再次进入向导。  
（已有业务数据的旧库会自动视为本地买断，避免误拦。）

**硬规则：**

1. 本地买断 **绝不** 使用云端 MySQL。  
2. SaaS **必须** 使用云端 MySQL（开发可用本机/容器 MySQL 代替远端）。  
3. 小程序 **只** 挂在 SaaS 云版。  

---

## A · 本地买断版

| 项 | 内容 |
|----|------|
| 配置 | `app.deployment=desktop`（默认），**不要** `spring.profiles.active=cloud` |
| 数据库 | SQLite：`~/.show/show.db`，Flyway `db/migration/sqlite` |
| 安装 | `scripts/package-desktop.bat` → MSI；内嵌 runtime，用户无需 JDK |
| 能力 | 会员 / 收银 / 员工 / 报表 / 店员角色 / 本机备份 |
| 关闭 | SaaS API 与 `/saas/`、微信小程序、云库 |
| 商业 | 一次性买断 |

启动：

```powershell
mvn spring-boot:run
# 或安装 MSI 后从开始菜单启动
```

---

## B · SaaS 云版

| 项 | 内容 |
|----|------|
| 配置 | `spring.profiles.active=cloud` 且 `app.deployment=cloud` |
| 数据库 | MySQL，Flyway `db/migration/mysql` |
| 安装 | `docker compose up` 或云主机部署 jar |
| 能力 | 上表全部 C 端能力 + 邀请开店 + 运营中台 + 到期/只读 + 小程序 |
| 商业 | 订阅制（套餐 free/plus/pro） |

启动示例：

```powershell
mvn spring-boot:run "-Dspring-boot.run.profiles=cloud"
# 或
docker compose up -d --build
```

详见 [云版Docker部署.md](./云版Docker部署.md)、[SaaS运营平台.md](./SaaS运营平台.md)、[商家小程序.md](./商家小程序.md)。

## 技术对照（同一套业务代码）

| | 本地买断 | SaaS 云 |
|--|----------|---------|
| Profile | 默认 | `cloud` |
| `app.deployment` | `desktop` | `cloud` |
| DB | SQLite | MySQL |
| Flyway location | `.../sqlite` | `.../mysql` |
| `/api/saas/**` | **403 门禁** | 正常 |
| `/saas/` | **404 说明页** | 运营台 SPA |
| 小程序 | 关闭 | 可开 |

接口查询当前 SKU：`GET /api/system/product-line`（含 `edition` / `licenseModel` / `skus`）。
