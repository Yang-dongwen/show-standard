# 截图说明

本目录存放根目录 README 使用的产品截图。

## 文件

| 文件 | 页面 |
|------|------|
| `01-login.png` | 登录 |
| `02-dashboard.png` | 经营总览 |

可按需要继续补充：`03-customers.png` 等。

## 如何截图

1. `frontend` 下 `npm run build` 后 `mvn spring-boot:run`  
2. 打开 `http://localhost:8080`，登录后截图  
3. 在根目录 `README.md` 中用 Markdown 引用  

勿使用早期桌面壳时代的旧截图文件名。
