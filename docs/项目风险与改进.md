## 2. P0 已实现说明

### 2.1 请求级租户门禁

- 位置：`AuthFilter`  
- 每个 C 端受保护请求：`TenantAccessService.assertCanLogin(tenantId)`  
- `POST/PUT/PATCH/DELETE`：再 `assertCanWrite`（停用/到期/只读）  
- 登录失败类 → **401**；只读写拒绝 → **403**

### 2.2 配置守卫

| 配置 | 含义 |
|------|------|
| `app.saas.bootstrap-enabled` | 是否允许启动时创建 SaaS 引导管理员（默认 `true` 便于本地/演示） |
| `app.saas.bootstrap-password` | 引导密码；为空则不创建管理员 |
| `app.security.strict-cloud` | `true` 时 cloud 禁止 wx mock、禁止 demo 微信密钥、禁止弱引导密码 |

cloud + `mock=true` 时启动会打 **醒目 WARN**（即使用非 strict）。

生产建议：

```yaml
app:
  security:
    strict-cloud: true
  saas:
    bootstrap-enabled: false
  wx:
    miniapp:
      enabled: true
      mock: false
      app-id: ${WX_MINI_APP_ID}
      app-secret: ${WX_MINI_APP_SECRET}
```

### 2.3 最小测试

```powershell
mvn test
```

覆盖：注册登录、充值消费余额、租户停用后接口 401、只读模式写 403 等（见 `src/test/java`）。

### 2.4 P1 已实现说明

| 项 | 说明 |
|----|------|
| 校验码 | 权限 `customers:verify`（默认仅店长）；列表 API 无权限不返回明文；CSV 导出本就不含校验码；消费校验失败写审计 |
| 权限 | `PermissionInterceptor` **fail-closed**；未映射路径 403；`/api/reports/dashboard` 用 `dashboard` 权限 |
| 限流 | `LoginRateLimiter`：C 端登录/wx、SaaS 登录按 IP/用户 15 分钟内失败超 10 次拒绝 |
| 登录审计 | 成功/失败写入 `t_audit_log`（失败时 tenant_id=0） |
| 帮助页 | 桌面托盘退出、用户名全局唯一、校验码非支付密码 |
